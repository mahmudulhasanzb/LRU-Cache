💡 Approach & Architectural Trade-offs

Passive (Lazy) Eviction on Read

When get(key) is called, the node's expiration timestamp is checked against Date.now(). If expired, it is immediately detached from the Doubly Linked List and removed from the Hash Map in O(1) time, returning -1. Zero background timer overhead.

Zero Timer Bottlenecks

Unlike active timer sweeps (e.g. setInterval), passive evaluation creates no event loop contention and no timer leaks in long-running services. Expired elements that are never read are effortlessly evicted when cache capacity is exceeded.
